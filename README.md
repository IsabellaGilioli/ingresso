# 🎫 Sistema de Ingressos

Projeto de sistema de compra de ingressos desenvolvido com **JavaScript, HTML e CSS**.

## 💡 Funcionalidades

- Seleção de tipo de ingresso
- Controle de quantidade disponível em tempo real
- Validação de compra (evita valores inválidos)
- Mensagens de erro e sucesso
- Atualização dinâmica do estoque na interface

## 🧠 Como funciona

O sistema verifica o tipo de ingresso selecionado, valida a quantidade solicitada e atualiza automaticamente o estoque disponível após cada compra.

## 🛠️ Tecnologias usadas

- HTML5
- CSS3
- JavaScript (DOM manipulation e lógica de validação)
